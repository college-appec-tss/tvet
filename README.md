# Rwanda TVET Student Hub

A responsive, static starter website for an independent Rwanda-focused TVET learning resource.

## Included
- Mobile-responsive homepage and navigation
- Subject landing pages for software development, networking, databases and computer systems
- Beginner guides for HTML, SQL and IP addressing
- Percentage calculator, weighted grade calculator and weekly study planner
- About, contact and starter privacy pages
- Page titles, descriptions, canonical tags, Open Graph metadata
- WebSite and calculator structured data
- `robots.txt`, `sitemap.xml`, favicon and social preview image

## Before publishing (important)
1. Replace every `https://YOUR-DOMAIN.example` with your real HTTPS domain in canonical tags, Open Graph URLs, JSON-LD, `robots.txt` and `sitemap.xml`.
2. Replace the placeholder email on `/contact/` with an email address you monitor.
3. Review the privacy notice against the analytics, ads, forms and third-party services you actually add.
4. Check every lesson against current course materials. Add original, accurate lessons and practical exercises; do not upload copyrighted notes or exam papers without permission.
5. Test all links, calculators, mobile layout and accessibility.
6. Deploy the folder as a static site (GitHub Pages, Netlify, Cloudflare Pages or another static host).
7. Add the domain to Google Search Console, verify ownership, submit `/sitemap.xml`, and inspect important URLs.

## SEO reality check
This starter site is technically prepared for crawling, but SEO setup cannot guarantee 100 visits per day. Search traffic depends on useful original content, competition, links/mentions, indexing, user satisfaction and time. Avoid keyword stuffing, fake backlinks and mass-generated thin pages.
